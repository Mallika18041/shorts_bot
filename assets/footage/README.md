# Your footage library

Put your own vertical (9:16) video clips in this folder. The bot picks one for each scene.

- Formats: .mp4 (best), .mov, .mkv, .webm
- Size: keep each file under 25 MB (the GitHub website's upload limit). 10 to 30 seconds each is plenty.
- Quantity: 25 to 40 different clips so videos don't repeat each other.
- Names help: put what the clip shows in the file name or in a sub-folder name, like `palace_01.mp4`,
  `fort_sunset.mp4`, `rain_window.mp4`, or `temple/arch2.mp4`. A scene about "old palace" then
  prefers clips with "palace" in the name. Other scenes pick any clip not yet used in that video.
- Only use clips you are allowed to use (Pexels, Pixabay and Mixkit clips are free for this).
